# Power BI Superstore Sales Dashboard

## Project Overview

This project presents an interactive Power BI dashboard developed to analyze sales performance using a Superstore-style retail dataset.

The dashboard provides insights into sales trends, product performance, customer segments, geographic performance, and overall business performance.

## Business Objectives

The main objectives of this project are to:

- Monitor overall sales performance
- Identify sales trends over time
- Analyze product and category performance
- Evaluate customer segment performance
- Identify top-performing products
- Analyze geographic sales performance
- Support data-driven business decision-making

## Dataset

The dataset contains retail sales transaction data with information such as:

- Order ID
- Order Date
- Ship Date
- Ship Mode
- Customer ID
- Customer Name
- Segment
- Country
- City
- State
- Region
- Product ID
- Category
- Sub-Category
- Product Name
- Sales

The dataset was obtained from a publicly available retail dataset.
